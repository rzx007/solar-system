# 3D 太阳系 · 程序化着色

单文件、离线可用的 3D 太阳系。**不使用任何贴图**——所有星球表面（大陆、海洋、冰盖、气态带纹、大红斑、太阳米粒组织）都由 GLSL 噪声着色器实时生成。

## 使用

**在线**：https://rzx007.github.io/solar-system/

**本地**：直接用浏览器打开 `index.html` 即可，无需服务器、无需联网（three.js 已内联进文件）。

## 交互

| 操作 | 效果 |
| --- | --- |
| 点击星球 / 右侧面板 | 聚焦到该天体，相机持续跟随 |
| 拖拽 | 旋转视角 |
| 滚轮 | 缩放（聚焦时按天体半径自动限位） |
| 右键拖拽 | 平移 |
| `1`–`8` | 聚焦对应行星 |
| `Esc` | 回到全景 |
| `空格` | 暂停/继续 |
| `O` / `L` | 切换轨道线 / 标签 |
| `[` / `]` | 降低 / 提高时间流速 |
| 拖动「流速」滑块 | 任意设定时间流速，实时生效 |

时间流速范围 `0.1 ~ 400 天/秒`，默认 `10 天/秒`。滑块与键盘共用同一条对数刻度（`daysPerSec = 0.1 × 4000^(p/1000)`，`p` 为滑块千分位），因此 `[` / `]` 与滑块位置始终同步。

## 内容

- 8 颗行星 + 月球、木卫一~四、土卫六，共 14 个天体（8 行星 + 6 卫星）
- 太阳：米粒组织、太阳黑子、临边昏暗、日冕与辉光
- 地球：程序化大陆地形、海洋高光、极冠、独立云层、大气散射
- 土星 / 天王星环：程序化环缝与密度变化，含行星投在环上的阴影
- 星空：约 9000 颗恒星，含色温分布与银河带聚集

## 构建

`logic_*.js` 是拼接用的源码分片，按顺序与 `build/head.html`（含内联 three.js）合并生成 `index.html`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build\rebuild.ps1
```

> 注意：`rebuild.ps1` 必须用显式 UTF-8 读写。PowerShell 5.1 的 `Get-Content -Raw` 对无 BOM 文件会按系统 ANSI 解码，会让中文乱码并破坏 HTML 标签结构。

## 已知问题

- **土卫六落在土星环内**：Titan 轨道半径 `dist:6.8`，而土星环外径为 `2.35×3.55=8.34`，且卫星轨道面与环共面，所以 Titan 会出现在环带内部。需要把 Titan 的 `dist` 调到环外（>8.34）。
- **地球表面可能被大气洗白（待人眼确认）**：离屏渲染 A/B 实测地球本体网格确实在写像素（约占画面 7.9%），并非"完全被遮住"；但大气壳是加法混合，仍可能压掉表面细节。

### 已核实为误判 / 已修复

- ~~**卫星不可见**~~：离屏 A/B 实测月球本体贡献 8.24%、木卫一 10.15% 的像素，**卫星是可见的**，原判断不成立。
- ~~**视角重置不干净**~~：已修复。`Esc` 后 `target`/`want` 精确归零、`dist`=`dDist`=210、`theta/phi` 与目标值一致、过渡偏移归零（均由 headless 探针实测）。

> 注：用"截图看像素"验证可见性时要小心。若劫持了 `requestAnimationFrame` 去驱动帧，浏览器就再无机会合成画面，截图会是空的——此时"画面全黑"是测试方法的问题，不是渲染缺陷。判定可见性应改为渲染到离屏 `WebGLRenderTarget` 后 `readRenderTargetPixels` 比对隐藏前后的差异。

## 验证方式

开发中使用无头 Edge + SwiftShader 做真实 WebGL 渲染验证（截图 + 像素分析 + 运行时错误捕获），而非仅做语法检查。着色器编译错误只在运行时暴露，语法检查无法覆盖。

相机跟随这类"帧与帧之间"的行为，用**假时钟探针**验证：在主循环脚本之前覆盖 `performance.now` 并把 `requestAnimationFrame` 换成手动队列，即可用固定 `dt` 精确驱动任意帧数，再读取 `camera` 与天体世界坐标的投影偏差。实测同一份参数下，旧的两级指数平滑跟踪会让木卫一偏离画面中心 38.2 个 NDC 单位（约 19 个屏宽），改成"过渡偏移衰减 + 刚性同步"后恒为 0。

### 回归测试

```powershell
node test/run.mjs
```

零依赖，只用 Node 内置模块 + 本地无头 Edge（`--allow-file-access-from-files` 加载 `file://` 下的 `index.html`），覆盖滑块/键盘/读数/HUD 一致性等 10 条用例。新增用例时用**变异测试**确认它真的会失败：故意改坏被测逻辑，看测试是否报错——本次就让 7 个变异全部被杀，同时发现并删掉了一段永远走不到的端点特判死代码。

> `--virtual-time-budget` 会让虚拟时间跑得比真实时间快得多，而 HUD 节流基于 `THREE.Clock` 的真实时间。写涉及 HUD 的用例时要直接调用 `updateHUD()`，别依赖帧循环自然触发。
